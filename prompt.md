EXISTING MACHINE LEARNING SYSTEM
================================

The ML model was trained separately in Google Colab.

The dataset contains approximately 50,000 knowledge-base documents.

The important dataset fields are:

* document_id
* category
* title
* content
* keywords

The existing preprocessing pipeline is:

1. Convert text to lowercase.
2. Remove non-alphanumeric characters.
3. Normalize whitespace.
4. Tokenize using NLTK word_tokenize.
5. Remove English stopwords.
6. Remove tokens with length <= 1.

The document text representation combines:

title + content + keywords

The primary production model is:

Word2Vec using Gensim

Configuration:

vector_size = 100
window = 5
min_count = 2
sg = 1
workers = 4
epochs = 20

The query is processed using the same preprocessing pipeline.

The query vector is generated by averaging the Word2Vec vectors of the recognized query tokens.

Document vectors are already generated.

Similarity is calculated using cosine similarity.

Results are ranked from highest similarity to lowest similarity.

DO NOT change this ML logic.

DO NOT replace Word2Vec with Sentence Transformers.

DO NOT replace it with an LLM.

DO NOT replace cosine similarity with another similarity algorithm.

DO NOT retrain the model.

The purpose of this project is to productionize the already-trained ML system.
